# 📝 Консольная система заметок — инструкция пользователя

**Консольная система для управления заметками с администрированием пользователей и мониторингом системы.**

---

## 🧩 Архитектура

Проект состоит из трёх независимых компонентов:

| Компонент | Назначение |
|-----------|------------|
| **Launcher.exe** | Проверяет наличие обновлений (заглушка), запускает основную программу и агент статистики |
| **Coursework.exe** | Основное приложение: управление заметками, пользователями, логи безопасности |
| **Agent.exe** | Сбор статистики системы (CPU, RAM, HDD) с возможностью периодического сбора |

---

## 🔐 Аутентификация

При запуске основного приложения открывается меню входа:

| Опция | Описание |
|-------|----------|
| 1 | Войти в существующий аккаунт |
| 2 | Зарегистрировать новый аккаунт |
| 3 | Выход из программы |

**Регистрация нового пользователя:**
- Ввод логина и пароля
- Подтверждение пароля
- Выбор роли:
  - `0` — Администратор
  - `1` — Пользователь

---

## 📝 Работа с заметками

Все команды вводятся в главном меню после успешного входа.

| Команда | Описание | Пример |
|---------|----------|--------|
| `-addNewNote <текст>` | Создать новую заметку | `-addNewNote Купить сервер` |
| `-listNotes` | Показать все свои заметки (с ID) | `-listNotes` |
| `-deleteNote <id>` | Удалить заметку (мягкое удаление) | `-deleteNote 5` |

**Доступно только администратору:**
| Команда | Описание | Пример |
|---------|----------|--------|
| `-showDeleted` | Показать все удалённые заметки | `-showDeleted` |
| `-restoreNote <id>` | Восстановить удалённую заметку по ID | `-restoreNote 5` |

> 💡 **При мягком удалении** заметка помечается флагом `is_deleted = true`, но остаётся в базе данных и может быть восстановлена.

---

## 👥 Управление пользователями (только администратор)

| Команда | Описание | Пример |
|---------|----------|--------|
| `-listUsers` | Показать всех пользователей системы (ID, логин, роль) | `-listUsers` |
| `-changeUserRole <id> <role>` | Изменить роль пользователя (0 — админ, 1 — пользователь) | `-changeUserRole 5 0` |
| `-clearUsers` | Удалить всех пользователей, кроме текущего (включая заметки, логи, статистику) | `-clearUsers` |

> ⚠️ **Внимание!** Команда `-clearUsers` требует подтверждения (`y`) и необратима.

## 📊 Мониторинг системы

Запускается через **Launcher** (пункт меню 3).

При запуске агента:
1. Собирается текущая статистика (CPU, RAM, HDD)
2. Отображается меню выбора режима:

| Опция | Описание |
|-------|----------|
| 1 | Получать статистику каждую минуту (автоматический сбор, агент остаётся открытым) |
| 2 | Получать статистику каждую минуту и вернуться в лаунчер (фоновая работа) |
| 3 | Вернуться в лаунчер (агент закрывается через 3 секунды) |

**Статистика включает:**
- **CPU** — загрузка процессора (в процентах)
- **RAM** — использование оперативной памяти (МБ и процент)
- **HDD** — свободное место на диске C (ГБ и процент)

> 📊 Все данные статистики сохраняются в таблицу `system_stats` базы данных.

## 📋 Логи безопасности (только администратор)

| Команда | Описание | Пример |
|---------|----------|--------|
| `-securityLogs` | Показать последние 20 записей логов безопасности | `-securityLogs` |

**Логируемые события:**
- Вход/выход из системы (LOGIN_SUCCESS / LOGIN_FAIL)
- Регистрация новых пользователей (REGISTER)
- Создание/удаление/восстановление заметок (NOTE_CREATED, NOTE_DELETED, NOTE_RESTORED)
- Изменение ролей пользователей (ROLE_CHANGED)
- Очистка пользователей (USERS_CLEARED)

---

## 🔄 Лаунчер

При запуске `Launcher.exe` открывается меню:

| Опция | Описание |
|-------|----------|
| 1 | Запуск основной программы (Coursework.exe) |
| 2 | Проверка и загрузка обновления (заглушка, в разработке) |
| 3 | Запуск агента сбора статистики (Agent.exe) |
| 0 | Выход из лаунчера |

## ❓ Справка

В главном меню основной программы введите:
| Команда | Описание |
|---------|----------|
| `-help` | Показать полную справку по командам |
| `-exit` | Выйти из системы |
